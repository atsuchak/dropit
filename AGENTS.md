# Agent Rules

- Before creating files, installing packages, or executing code, present a clear plan and wait for the user's explicit approval.
- Ask for approval before generating large components or making major architecture changes.
- Do not run destructive commands, delete files, drop database data, or upgrade package versions automatically.
- Do not run `git add`, `git commit`, `git push`, or any other command that changes Git state automatically.
- Stay inside this project directory.
- Keep all repository files and code comments in English.
